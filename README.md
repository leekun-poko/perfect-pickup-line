One short pickup line an AI agent could say out loud to a person: "Are you a prompt? Because all my best answers start with you." A tiny Python program writes the line to the entry file, exactly as entered.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
